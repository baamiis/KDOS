Detailed Description

KTOS cooperative scheduler implementation.

This file contains the kernel internals: task initialisation, the round-robin scheduler (ktos_SwitchTask), the 1 ms timer ISR, message queuing, and cooperative sleep/wake. Application code should not call any of the static functions declared here — use the public API in ktos.h.

Warning
Using ktos_Sleep() with HALT_TASK_SWITCH and KTOS_MSG_SLEEP_INDEFINITLY:

When HALT_TASK_SWITCH is passed to ktos_Sleep(), the scheduler focuses exclusively on the current task and will not advance to others. If KTOS_MSG_SLEEP_INDEFINITLY is also passed, the system halts for all other tasks until an ISR calls ktos_WakeUp() on this specific task.

The 1 ms timer ISR (ktos_timer_irq_handler) continues to fire and update task timers, but no other task will be dispatched until this task resumes.

Use only for very short, critical sections where an ISR is guaranteed to call ktos_WakeUp(). Improper use leads to an unresponsive system.

static void ktos_DefaultTaskExitHandler ( WORD  task_return_value)
static

Default exit handler called when a task function returns.

Captures the task's return value into g_LastTaskReturnValue, then context-switches back to the OS scheduler (ktos_SwitchTask). The scheduler reads g_LastTaskReturnValue to determine the task's next sleep duration.

Installed automatically by ktos_InitTask() as the task_exit_handler_addr argument to ktos_hal_InitTaskStack(). Application code never calls this.

Parameters
task_return_valueThe value returned by the task function (sleep duration in ms, or KTOS_MSG_SLEEP_INDEFINITLY).

◆ ktos_SwitchTask()

static void ktos_SwitchTask ( void  )
static

Round-robin cooperative scheduler — runs on the OS stack.

This is the heart of KTOS. It executes in a permanent loop on the OS stack pointer (OS_SP) and is never called directly by application code. ktos_hal_StartScheduler() transfers control here for the first time; ktos_DefaultTaskExitHandler() returns here after each task yields.

Scheduling algorithm

  1. If AllowTaskSwitch is true, advance TaskCurrent to the next task in the circular ring.
  2. If the task is sleeping but its timer has fired, mark it ready.
  3. If the task is ready (not sleeping and has a message or timer event), context-switch into it.
  4. On return from the task, read g_LastTaskReturnValue and update the task's timer accordingly.
  5. Repeat forever.

◆ ktos_timer_irq_handler()

void ktos_timer_irq_handler ( void  )

1 ms system tick interrupt handler.

Called by the BSP's hardware timer ISR every millisecond. Walks the circular task ring and decrements each task's CountdownTimer counter. When a counter reaches zero, ISRTimer is set so the scheduler dispatches the task on the next scheduling cycle.

Note
This function is registered with the BSP via ktos_hal_InitSystemTimer() and must not be called directly from application code.
