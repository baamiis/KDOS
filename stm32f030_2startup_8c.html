Detailed Description

STM32F030R8 (Nucleo) bare-metal startup.

Provides:

  • Vector table (.vectors at 0x08000000)
  • Reset_Handler: 48 MHz PLL clock init, .data copy, .bss zero, main()
  • Default_Handler: infinite loop for unhandled exceptions

Clock chain: HSI 8 MHz → HSI/2 (4 MHz) → PLL ×12 → SYSCLK 48 MHz AHB = 48 MHz, APB = 48 MHz

Every main.c must define: void SysTick_Handler(void) { ktos_timer_irq_handler(); }
