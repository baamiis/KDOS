Supported boards: Arduino Mega 2560.

Property Value

RAM 8 KB
Flash 256 KB
Clock 16 MHz
Toolchain avr-gcc

avr-gcc -mmcu=atmega2560 -DF_CPU=16000000UL ...

1 ms system tick interrupt handler.

Note
ATmega2560 has 256KB flash (128K words), so the hardware pushes a 3-byte PC on CALL/RET. InitTaskStack must push 3 bytes per return address (PCL, PCH, PCEXT).
