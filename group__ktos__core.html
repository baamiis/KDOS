◆ ktos_ExitOS()

void ktos_ExitOS ( void  )

#include <core/ktos.h>

Signal the scheduler to exit ktos_RunOS() after the current task yields.

Intended for platforms where the host event loop (e.g. ESP8266 ets_run()) must resume after KTOS has finished its work. Call from task context just before returning KTOS_MSG_SLEEP_INDEFINITLY. ktos_RunOS() returns to its caller on the next scheduler cycle.

Has no effect if called from ISR context or before ktos_RunOS().

#include <core/ktos.h>

Enqueue a message for delivery to a task.

Thread-safe: interrupts are briefly disabled while writing to the queue. May be called from ISR context.

If the target task's queue is full the message is discarded and false is returned — no assertion or error is raised.

◆ ktos_Sleep()

int ktos_Sleep ( unsigned short int  Delay,
bool  TaskAllowSwitch 
)

#include <core/ktos.h>

Yield the CPU for a given duration and optionally allow other tasks to run.

The task suspends itself for Delay milliseconds. When the timer expires the scheduler delivers KTOS_MSG_TYPE_TIMER on the next invocation. Call from task context only — never from an ISR.

Equivalent to returning Delay directly from the task function; the difference is that ktos_Sleep() can be invoked deep inside a call stack.

Parameters
DelaySleep duration in milliseconds.
  • 0 — yield immediately (run other tasks once, then resume).
  • 1–65534 — sleep for that many milliseconds.
  • KTOS_MSG_SLEEP_INDEFINITLY — sleep indefinitely until ktos_WakeUp() is called.
TaskAllowSwitchALLOW_TASK_SWITCH (1) — allow other tasks to run while sleeping. HALT_TASK_SWITCH (0) — freeze scheduler; only this task can resume (requires ISR to call ktos_WakeUp()).
Returns
The TaskTypeWakeUp value supplied by the ktos_WakeUp() call that woke this task, or 0 if woken by the timer.
Warning
Passing both KTOS_MSG_SLEEP_INDEFINITLY and HALT_TASK_SWITCH halts all other tasks until an ISR calls ktos_WakeUp(). Use with extreme caution.

Example

// Inside a task function — wait 200 ms then continue
ktos_Sleep(200, ALLOW_TASK_SWITCH);
// Execution resumes here after 200 ms

◆ ktos_WakeUp()

void ktos_WakeUp ( struct ktos_TASK *  Task,
INT  TaskTypeWakeUp 
)

#include <core/ktos.h>

Wake a sleeping task immediately from an ISR or another task.

Sets the task's ISRTimer so the scheduler will dispatch it on the next scheduling cycle. Safe to call from ISR context.

Has no effect if the task is not currently sleeping.

Parameters
TaskTask to wake (returned by ktos_InitTask()).
TaskTypeWakeUpArbitrary value returned to the sleeping task by ktos_Sleep(). Use this to communicate why the task was woken (e.g. which peripheral triggered the event).

Example — wake a task from a button ISR

void EXTI0_IRQHandler(void)
{
ktos_WakeUp(g_ui_task, WAKE_BUTTON_PRESS);
}
// Inside g_ui_task:
int reason = ktos_Sleep(KTOS_MSG_SLEEP_INDEFINITLY, ALLOW_TASK_SWITCH);
if (reason == WAKE_BUTTON_PRESS) { handle_button(); }
