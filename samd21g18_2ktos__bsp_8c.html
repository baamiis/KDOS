Detailed Description

KTOS Board Support Package — Atmel ATSAMD21G18 (ARM Cortex-M0+)

Supported boards: Arduino Zero.

Property Value
Core ARM Cortex-M0+
RAM 32 KB
Flash 256 KB
Clock 48 MHz (DFLL48M)
Toolchain arm-none-eabi-gcc

Tick source: TC3 (IRQ 18 in peripheral table, NVIC bit 18). TC3 is clocked from GCLK0 (48 MHz), MFRQ mode, CC0=47999 → 1 ms.

Cortex-M0+ context switch differs from M3: push/pop of high registers (R8-R11) must be done indirectly via R4-R7.

void TC3_Handler(void) {

ktos_timer_irq_handler();
}
