Detailed Description

KTOS Board Support Package — STM32L031 (ARM Cortex-M0+)

Supported boards: Nucleo-L031K6.

Property Value
Core ARM Cortex-M0+
RAM 8 KB
Flash 32 KB
Clock 4 MHz (MSI default)
Toolchain arm-none-eabi-gcc

Build

arm-none-eabi-gcc -mcpu=cortex-m0plus -mthumb --specs=nosys.specs ...

Cortex-M0+ assembly constraints

  • Only low registers (R0-R7) can be used with most Thumb instructions.
  • R8-R11 must be moved to low registers via MOV before push/store.
  • STR with SP as source is not permitted — use MOV R2, SP first.
